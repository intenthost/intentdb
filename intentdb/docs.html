Client Integrations

Examples for integrating with IntentDB using npm, native fetch, or server actions.

npm package usage 
npm install intentdb
app.js (ESM / TypeScript) 
import { intentdb } from 'intentdb';

// Automatically connects to process.env.DATABASE_URL
const db = intentdb();

// 1. Tagged template query (Auto-parameterized & SQL-injection safe)
const users = await db`SELECT id, email FROM users WHERE status = ${'active'}`;

// 2. Standard query with explicit params
const { rows } = await db.query('SELECT * FROM products WHERE id = $1', [42]);

// 3. Atomic transaction (Rolls back automatically on failure)
await db.transaction([
  { query: 'UPDATE accounts SET balance = balance - $1 WHERE id = $2', params: [50, 1] },
  { query: 'UPDATE accounts SET balance = balance + $1 WHERE id = $2', params: [50, 2] }
]);

// 4. Real-time latency ping
const { status, response } = await db.ping(); // { status: "ok", response: "4ms" }
Zero-dependency helper (paste directly into project) 
const _u = new URL(process.env.DATABASE_URL);
export const query = (sql, params = []) => fetch(`${_u.origin}/query`, {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Authorization': `Bearer ${_u.username}`
  },
  cache: 'no-store',
  body: JSON.stringify({ query: sql, params })
}).then(r => r.json());

// Usage:
const { rows } = await query('SELECT * FROM users WHERE id = $1', [1]);
app/page.tsx (Next.js Server Component) 
import { intentdb } from 'intentdb';

const db = intentdb();

export default async function Page() {
  const users = await db`SELECT id, name FROM users LIMIT 10`;

  return (
    <main>
      <h1>Users</h1>
      <ul>
        {users.map((u: any) => (
          <li key={u.id}>{u.name}</li>
        ))}
      </ul>
    </main>
  );
}

Route Reference

Route Method Auth Description
/ or /health GET Public Live DB round-trip latency check: {"status":"ok","response":"5ms"}
/stats GET API Key Gateway connection pool metrics and process status.
/query POST API Key Execute parameterized SQL query. Body: {"query":"...", "params":[...]}
/transaction POST API Key Atomic multi-query execution. Rolls back on error.
/batch POST API Key Parallel queries via Promise.allSettled.
/docs GET Public Interactive single-page documentation and SQL console.

Disabling Documentation

To run IntentDB as a 100% headless, private JSON API without web documentation:

Option 1: In your gateway .env file:
Set ENABLE_DOCS=false. Requests to GET /docs will immediately return HTTP 404.

Option 2: Delete docs.html:
Removing docs.html disables the route safely without affecting any database queries.
